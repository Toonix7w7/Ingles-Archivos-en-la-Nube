// GLOSSARY

Glosario de Términos Técnicos

Lista de vocabulario técnico fundamental para la documentación.

  • Cloud Storage: Almacenamiento de datos en servidores remotos accesibles vía internet.
  • AWS (Amazon Web Services): Plataforma líder de servicios de computación en la nube en la nube pública.
  • Azure: Plataforma de servicios en la nube desarrollada por Microsoft para crear y gestionar aplicaciones.
  • Google Cloud Platform (GCP): Suite de servicios de desarrollo y almacenamiento en la nube de Google.
  • IaaS (Infrastructure as a Service): Provisión de infraestructura informática (servidores, redes) a través de internet.
  • PaaS (Platform as a Service): Entorno de desarrollo en la nube listo para construir, probar y desplegar software.
  • SaaS (Software as a Service): Modelo donde el software se entrega a través de internet como un servicio.
  • Serverless: Modelo de ejecución en la nube donde el proveedor gestiona la asignación dinámica de recursos.
  • Data Center (Centro de Datos): Instalación física que alberga infraestructura crítica de servidores y redes.
  • Virtual Machine (VM): Entorno virtualizado que simula un sistema de cómputo físico independiente.
  • Docker: Plataforma de software para empaquetar aplicaciones en contenedores ligeros y portables.
  • Kubernetes: Sistema de código abierto para automatizar la implementación y gestión de contenedores.
  • Scalability (Escalabilidad): Capacidad de un sistema para manejar un crecimiento de carga de trabajo sin perder rendimiento.
  • Load Balancer (Balanceador de Carga): Dispositivo o software que distribuye el tráfico de red entre varios servidores.
  • Multi-Cloud: Estrategia de utilizar servicios de dos o más proveedores de nube simultáneamente.
  • API (Application Programming Interface): Interfaz de comunicación entre diferentes aplicaciones de software.
  • REST (Representational State Transfer): Estilo de arquitectura de software para diseñar servicios web eficientes.
  • JSON (JavaScript Object Notation): Formato de intercambio de datos ligero y fácil de leer para humanos y máquinas.
  • HTML (HyperText Markup Language): Lenguaje de marcado estándar para la estructura de páginas web.
  • CSS (Cascading Style Sheets): Lenguaje utilizado para definir el diseño visual y presentación de documentos HTML.
  • JavaScript: Lenguaje de programación interpretado para crear interactividad en sitios web.
  • Frontend: Capa de presentación visual con la que interactúa directamente el usuario en una web.
  • Backend: Capa lógica del servidor, manejo de datos y reglas de negocio detrás de la interfaz.
  • DOM (Document Object Model): Estructura jerárquica de nodos que representa la interfaz de una página HTML.
  • SPA (Single Page Application): Aplicación web que carga una sola página y actualiza contenido dinámicamente.
  • Responsive Design: Filosofía de diseño web para adaptar la interfaz a diferentes tamaños de pantalla.
  • PDF (Portable Document Format): Formato estándar para almacenar documentos de manera independiente del SO.
  • Repositorio: Almacén digital centralizado donde se gestiona y guarda código fuente o archivos de un proyecto.
  • Framework: Estructura conceptual y tecnológica estandarizada que sirve de base para desarrollar software.
  • Git: Sistema de control de versiones distribuido para rastrear cambios en el código fuente.
  • Encryption (Cifrado): Proceso de codificar datos para evitar que personas no autorizadas accedan a ellos.
  • SSL/TLS: Protocolos criptográficos que proporcionan comunicaciones seguras sobre una red de cómputo.
  • HTTPS: Versión segura del protocolo HTTP que utiliza cifrado TLS para proteger la transmisión de datos.
  • Firewall: Sistema de seguridad de red que monitorea y filtra el tráfico entrante y saliente.
  • MFA (Authentication Multi-Factor): Sistema de verificación de identidad que requiere dos o más evidencias.
  • Latency (Latencia): El tiempo de retraso de transmisión entre la emisión y recepción de un paquete de datos.
  • Bandwidth (Ancho de Banda): Cantidad máxima de datos que pueden transmitirse por una conexión en un tiempo dado.
  • IP Address: Etiqueta numérica que identifica de manera única a un dispositivo en una red.
  • DNS (Domain Name System): Sistema que traduce nombres de dominio legibles a direcciones IP numéricas.
  • CDN (Content Delivery Network): Red distribuida de servidores para entregar contenido web a alta velocidad.
  • Token: Clave de seguridad temporal utilizada para autenticar peticiones entre clientes y servidores.
  • Cybersecurity (Ciberseguridad): Práctica de proteger sistemas, redes y programas contra ataques digitales.
  • VPN (Virtual Private Network): Tecnología que crea una conexión de red cifrada y segura sobre redes públicas.
  • Zero Trust: Modelo de seguridad que exige verificación estricta para cada usuario y dispositivo.
  • Backup (Copia de Seguridad): Duplicado de datos realizado para recuperar información en caso de pérdida.
  • OCR (Optical Character Recognition): Tecnología para convertir texto dentro de imágenes en texto editable.
  • Traducción Automática: Proceso de traducción de texto o voz entre idiomas mediante modelos de software.
  • AI (Artificial Intelligence): Simulación de procesos de inteligencia humana por parte de sistemas informáticos.
  • Machine Learning: Rama de la IA que permite a los sistemas aprender y mejorar automáticamente con datos.
  • Deep Learning: Subcampo del Machine Learning basado en redes neuronales artificiales profundas.
  • NLP (Natural Language Processing): Campo de la IA enfocado en la interacción entre computadoras y lenguaje humano.
  • LLM (Large Language Model): Modelo de IA entrenado con grandes volúmenes de texto para procesar lenguaje.
  • Algorithm (Algoritmo): Conjunto de instrucciones ordenadas y finitas para resolver un problema específico.
  • Prompt: Texto o instrucción de entrada proporcionada a un modelo de IA para obtener una respuesta.
  • Dataset: Colección estructurada de datos utilizada para entrenar o evaluar modelos de análisis y Machine Learning.
  • Neural Network (Red Neuronal): Modelo computacional inspirado en la estructura del cerebro humano.
  • Computer Vision: Campo de la IA que permite a las computadoras interpretar y procesar información visual.
  • Tokenization (Tokenización): Proceso de dividir una cadena de texto en unidades pequeñas (palabras o subpalabras).
  • Data Mining: Proceso de descubrir patrones, anomalías y correlaciones en grandes conjuntos de datos.
  • Big Data: Conjuntos de datos masivos y complejos que requieren software avanzado para ser procesados.
  • UI (User Interface): Elementos visuales y de interacción con los que un usuario controla un sistema.
  • UX (User Experience): Experiencia y nivel de satisfacción general que tiene un usuario al usar un producto.
  • Usability (Usabilidad): Medida en la que un producto o sitio web es fácil y claro de utilizar.
  • Wireframe: Boceto o esquema visual básico de la estructura de una interfaz de usuario.
  • Prototype (Prototipo): Modelo preliminar de un sistema o interfaz utilizado para pruebas de interacción.
  • Accessibility (Accesibilidad): Diseño de sistemas para que sean utilizables por personas con discapacidades.
  • Middleware: Capa de software que conecta y permite la comunicación entre distintas aplicaciones.
  • CI/CD: Integración y despliegue continuos para automatizar las fases de desarrollo de software.
  • Database (Base de Datos): Sistema organizado para recopilar, almacenar y gestionar datos digitales.
  • SQL: Lenguaje de dominio específico utilizado para gestionar bases de datos relacionales.
  • NoSQL: Bases de datos diseñadas para almacenar datos no estructurados o de esquema flexible.
  • Query (Consulta): Solicitud formal de información a una base de datos o motor de búsqueda.
  • Cache: Memoria de acceso rápido que almacena temporalmente datos para acelerar lecturas futuras.
  • Asynchronous (Asíncrono): Proceso informático que se ejecuta en segundo plano sin bloquear el hilo principal.
  • Webhook: Mecanismo automatizado para enviar información en tiempo real de una aplicación a otra vía HTTP.
  • CRUD: Acrónimo de Crear, Leer, Actualizar y Borrar (operaciones básicas de una base de datos).
  • DevOps: Conjunto de prácticas que combinan el desarrollo de software (Dev) y las operaciones (Ops).
  • Open Source: Software cuyo código fuente está disponible públicamente para inspección y modificación.
  • Bug: Error o fallo en un programa de software que produce un resultado imprevisto o incorrecto.
  • Log: Registro cronológico automático de eventos y actividades que ocurren en un sistema informático.
