¿Qué es el Almacenamiento en la Nube?

Es un modelo de servicio donde los datos se transmiten y almacenan en sistemas de almacenamiento remotos.

// GLOSSARY

Glosario de Términos Técnicos y Cloud Storage

Lista de vocabulario técnico fundamental para la documentación y lectura de recursos en inglés.

  • Cloud Storage: Almacenamiento en la nube.
  • Storage: Almacenamiento / Guardado de datos.
  • Backup: Copia de seguridad.
  • Data: Datos / Información procesada.
  • Database: Base de datos.
  • File: Archivo / Documento.
  • Folder / Directory: Carpeta / Directorio.
  • Upload: Subir o cargar un archivo a un servidor.
  • Download: Descargar o bajar un archivo localmente.
  • Sync / Synchronization: Sincronización de archivos en tiempo real.
  • Server: Servidor de procesamiento y almacenamiento.
  • Client: Cliente o dispositivo que solicita información.
  • Remote Access: Acceso remoto a recursos.
  • Host: Anfitrión o equipo que aloja servicios.
  • Hosting: Alojamiento web o de archivos.
  • Network: Red de computadoras.
  • Bandwidth: Ancho de banda de transferencia.
  • Latency: Latencia o tiempo de respuesta.
  • Throughput: Rendimiento o velocidad de procesamiento efectivo.
  • IP Address: Dirección IP de un dispositivo en la red.
  • DNS (Domain Name System): Sistema de Nombres de Dominio.
  • Protocol: Protocolo de comunicación.
  • HTTP / HTTPS: Protocolos de transferencia de hipertexto (seguro).
  • FTP (File Transfer Protocol): Protocolo de transferencia de archivos.
  • Endpoint: Punto de extremo o nodo de conexión.
  • Gateway: Puerta de enlace de red.
  • Router: Enrutador de datos.
  • Firewall: Cortafuegos o barrera de seguridad de red.
  • Proxy: Servidor intermediario.
  • VPN (Virtual Private Network): Red privada virtual.
  • Encryption: Cifrado / Encriptación de datos.
  • Decryption: Descifrado de información.
  • Ciphertext: Texto cifrado no legible.
  • Plaintext: Texto plano o sin cifrar.
  • Authentication: Autenticación de identidad.
  • Authorization: Permiso o autorización de acceso.
  • Credentials: Credenciales de acceso (usuario y clave).
  • Access Control: Control de acceso a recursos.
  • Permission: Permiso de lectura o escritura.
  • Token: Ficha o clave temporal de autenticación.
  • Session: Sesión activa de usuario.
  • Multi-Factor Authentication (MFA): Autenticación de múltiple factor.
  • Password: Contraseña de seguridad.
  • Hash: Algoritmo de verificación de integridad.
  • Key: Llave criptográfica.
  • SaaS (Software as a Service): Software como servicio.
  • PaaS (Platform as a Service): Plataforma como servicio.
  • IaaS (Infrastructure as a Service): Infraestructura como servicio.
  • Public Cloud: Nube pública.
  • Private Cloud: Nube privada.
  • Hybrid Cloud: Nube híbrida.
  • Multi-cloud: Estrategia de múltiples proveedores de nube.
  • API (Application Programming Interface): Interfaz de programación de aplicaciones.
  • REST API: Arquitectura para servicios web ligeros.
  • Middleware: Software intermediario entre sistemas.
  • Microservices: Arquitectura basada en microservicios independientes.
  • Container: Contenedor de aplicaciones (ej. Docker).
  • Kubernetes: Orquestador de contenedores en la nube.
  • Virtual Machine (VM): Máquina virtual.
  • Hypervisor: Software gestor de máquinas virtuales.
  • Data Center: Centro de procesamiento de datos.
  • Redundancy: Redundancia de almacenamiento para prevención de fallos.
  • Replication: Replicación de datos en varios servidores.
  • Disaster Recovery: Plan de recuperación ante desastres.
  • Failover: Conmutación por error a un sistema de respaldo.
  • Availability: Disponibilidad del servicio.
  • Uptime: Tiempo de actividad o funcionamiento continuo.
  • Downtime: Tiempo de inactividad o caída del servicio.
  • Scalability: Escalabilidad o capacidad de crecimiento del sistema.
  • Load Balancing: Balanceo de carga de tráfico en servidores.
  • Migration: Migración de datos entre plataformas.
  • Archiving: Archivo a largo plazo de datos poco usados.
  • Cold Storage: Almacenamiento en frío para respaldos raramente consultados.
  • Hot Storage: Almacenamiento de alto rendimiento de acceso frecuente.
  • Blob (Binary Large Object): Objeto binario grande no estructurado.
  • Source Code: Código fuente.
  • Framework: Marco de trabajo de software.
  • Library: Librería de código reusable.
  • Repository: Repositorio de código o documentos.
  • Branch: Rama de desarrollo en sistemas de control de versiones.
  • Commit: Confirmación de cambios en código.
  • Merge: Fusión de código de distintas ramas.
  • Pull Request: Solicitud de integración de código.
  • Deploy / Deployment: Despliegue de aplicaciones en producción.
  • Bug: Error o fallo en el software.
  • Debug: Depuración o corrección de errores.
  • Patch: Parche o actualización de software.
  • Release: Lanzamiento de una nueva versión.
  • JSON (JavaScript Object Notation): Formato ligero de intercambio de datos.
  • XML: Lenguaje de marcado extensible para estructurar datos.
  • Cache: Memoria caché para acceso ultrarrápido.
  • CDN (Content Delivery Network): Red de distribución de contenido geográfico.
  • Node: Nodo o punto de conexión dentro de un sistema distribuido.
  • Traffic: Tráfico de red o flujo de datos.
  • Request: Petición de datos enviada por un cliente.
  • Response: Respuesta devuelta por el servidor.
  • Header: Encabezado con metadatos de la petición o archivo.
  • Payload: Carga útil o datos reales transmitidos.
  • Timeout: Tiempo límite de espera agotado.
  • Socket: Punto final para comunicación bidireccional en tiempo real.
  • WebSockets: Protocolo para comunicación cliente-servidor persistente.
  • Port: Puerto de comunicación lógico de red.
  • DNS Lookup: Búsqueda y resolución de direcciones DNS.
  • Ping: Diagnóstico de tiempo de respuesta de red.
  • Packet: Paquete de datos transmitido en red.
  • Big Data: Análisis de grandes volúmenes de datos.
  • Data Mining: Minería y extracción de patrones de datos.
  • Data Analytics: Análisis y procesamiento estadístico de datos.
  • Machine Learning: Aprendizaje automático orientado a datos.
  • Artificial Intelligence (AI): Inteligencia Artificial.
  • Algorithm: Algoritmo de procesamiento paso a paso.
  • Metadata: Datos que describen otros datos (fecha, tamaño, tipo).
  • Log File: Archivo de registro de eventos del sistema.
  • Audit Trail: Pista o registro de auditoría de seguridad.
  • Compliance: Cumplimiento normativo y legal de manejo de datos.
  • GDPR: Reglamento general de protección de datos.
  • Privacy: Privacidad y protección de información sensible.
  • Leak: Filtración no autorizada de información.
  • Breach: Brecha de seguridad en la infraestructura.
  • Vulnerability: Vulnerabilidad o debilidad de un sistema.
